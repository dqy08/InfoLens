Privacy Policy for Semantic Highlight

Last updated: September 2026

Data We Process

When you search a webpage or PDF (toolbar icon, Ctrl+Shift+F / Command+Shift+F, or the page context menu), the extension sends two things to our backend server at api.info-lens.app:

  • The search query you type (or the selected text, if you started from the context menu)
  • The visible text of the article/body content of the page you are currently viewing

This data is sent only when you actively invoke the extension on the page you are viewing at that moment. The extension does not run in the background and does not access any other tabs or pages.

Separately, and without page content: we use an anonymous client id (a random UUID). It is stored as a first-party cookie on info-lens.app (shared with our website and our other Info Lens extensions) and cached in the extension’s local storage. Installing, updating, uninstall events, and optional survey answers may include this id together with the extension id and version. If you submit the uninstall survey, we receive the reasons and comment you typed. The id is not linked to your name, email, or Google account. If you tap the in-product report button, we receive the error text, current page URL, query, extension version, and browser user agent.

How We Use It

The query and page text are used solely to compute semantic similarity and matching words, which the extension then highlights on the page. Version events, optional reports, optional survey answers, and the anonymous client id are used only to operate and improve the product. No other use is made of this data.

Data We Do Not Collect

We do not collect or store: names, email addresses, passwords, financial information, health information, personal communications, or any other personally identifiable information. We do not track your browsing history across pages or sessions.

Data Storage & Retention

  • Query text and page content are processed to generate search results. We do not keep them on our server after the response is returned.
  • Optional error reports and uninstall-survey answers are stored so we can diagnose issues and improve the product. Install/update/uninstall events may store the extension id, version, and anonymous client id.
  • Your recent search queries and a local analysis cache are saved in your browser (via the extension's local storage) so searches can be reused. You can clear the cache from the options page. Clearing site data for info-lens.app resets the anonymous client id cookie.

Third-Party Sharing

To compute matches, our backend forwards the query and page text to OpenRouter, a language-model API, solely for that request. We do not sell your data or use it for advertising.

Security

All data is transmitted over HTTPS.

Permissions

The extension requests the minimum permissions needed for its single purpose (semantic search on the active page):

  • activeTab / scripting: to read and highlight text on the page you are currently viewing, only when you invoke the extension
  • storage: to save your recent search queries and analysis cache locally in your browser
  • contextMenus: so you can start a search from the page's right-click menu

Optional host access is requested only for local PDF files (file://). The extension does not declare host permissions for our API. Query and page text are sent to our backend by the extension’s background service worker via a standard cross-origin HTTPS request; the page you are viewing never talks to our server directly.

Changes to This Policy

If our data practices change, we will update this policy and the Chrome Web Store listing accordingly.
